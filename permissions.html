Allow Crawl Pilot to read the pages you scrape

Crawl Pilot needs permission to access websites so its extractors can see the page content you point them at. Chrome will ask you to confirm.

  • Pick elements and preview data directly on the page with the visual selector.
  • Run list, page, and metadata extractions — including bulk runs across many URLs.
  • Everything stays on your device: extracted data is stored locally, never sent to a server.

You can change this anytime in chrome://extensions → Crawl Pilot → Site access.
