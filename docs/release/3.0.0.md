# CrawlPilot 3.0.0

Tag: `v3.0.0`. Package: `chrome-extension.zip` (`npm run zip`), 1.2 MB, 228 files, no source maps.

## What's new (store "What's new" / announcement)

**Pick a list in two clicks, run it on slow computers too**
- The picker reads the section under your cursor and its own cards, and is 2–3× faster on slow machines.
- Fields are typed (prices, ratings, review counts, IDs), split where a site packs several values together, and found again by their meaning when a site changes its layout.
- List runs: Stop always ends the run and keeps the rows read so far. "Next page" runs continue across pages reliably.

**Page Extractor runs out of sight**
- Many URLs run in hidden background tabs, with no windows over your work.
- Steps run in your recipe's order, clicks are checked for an effect, and Job details shows coverage per field.
- CrawlPilot suggests how many tabs at a time suit your computer, and eases off when it struggles.

**Page assistant (on-device AI, nothing leaves your computer)**
- A brief made for the kind of page (product, article, listing, job, recipe…), every point checked against the page and shown on it.
- Answers with citations, as tables you can save, in your language (on-device translation).
- Ask about an image or chart on the page.
- "What changed since I saved this?" and "Does it fit me?".

**New tools**
- **Contacts from websites:** emails, phones and social profiles from a list of company sites, one row per company.
- **API recipes:** the Scraper Toolkit finds the JSON API behind a page; "Get every page" calls it page by page with your session, with no tab per page.
- **Live Google Sheets sync:** send a dataset to your own Google Sheet (a script you own, no CrawlPilot account); new rows follow automatically.
- **Image Downloader:** full-size originals, duplicates removed, convert and resize.
- **Markdown** of any page, and **AI Extract** with grounded values.

**Faster and lighter**
- The side panel opens about 40% faster; only English is bundled, and other languages load when used.

## Permissions: justifications for the Chrome Web Store form

| Permission | Why |
|---|---|
| `activeTab` | Reads the page the user is on when they open CrawlPilot or click a tool. |
| `scripting` | Starts CrawlPilot's reader in the user's tab and in the background tabs of a run, and records a page's API calls when the user asks (API Finder). |
| `storage` | Settings, run state that survives a service-worker restart, and the user's saved preferences. Data stays in the browser. |
| `sidePanel` | CrawlPilot's interface is a side panel. |
| `downloads` | Exports (CSV, JSON, Excel) and the Image Downloader save files the user asked for. |
| `alarms` | Keeps the background service worker alive during a long run the user started (many URLs), so it isn't cut off part way. |
| Optional `<all_urls>` | Asked for when the user starts a run over several pages or sites. Chrome starts CrawlPilot only on sites it may read, so a run can continue on the next page or site. Also used for the user's own Google Apps Script (Sheets sync) and webhooks. |

**Single purpose:** extracting data the user chooses from web pages into tables they can export.

**Remote code:** none. All code is in the package; the on-device model is Chrome's own (Prompt API).

## Data use (privacy form)

- **Collected by CrawlPilot:** nothing. No analytics, no account needed for the features above.
- **Stays on the device:** pages read, extracted data, briefs, and AI prompts and answers (Gemini Nano runs on the device).
- **Sent only where the user points it:**
  - their own Google Apps Script web app (Sheets sync);
  - webhooks they configure;
  - the sites they scrape (with their own session).
- **Privacy policy:** the URL on the dashboard (crawlpilot.tech). Check that it exists and mentions the Sheets sync and the contacts finder before submitting.

## Submission checklist

1. `npm run zip`, then check `chrome-extension.zip` (version 3.0.0, no `key` in `manifest.json`, no `.map` files).
2. Load the unpacked `dist/` in a clean Chrome profile and try:
   - a list in two clicks;
   - a "Next page" run over 2+ pages, then Stop;
   - Page assistant on a product page;
   - Contacts on 2 sites;
   - API Finder "Get every page";
   - Sheets connect with a real Apps Script.
3. Developer Dashboard → CrawlPilot → Package → Upload new package.
4. Store listing:
   - the summary above;
   - the description updated with the new tools;
   - new screenshots (1280×800): picker, Page assistant, Contacts, API Finder, Sheets.
5. Privacy tab:
   - permission justifications above;
   - `<all_urls>` explained as optional;
   - data-use answers above.
6. Submit for review. The new optional host access and the new features may mean a longer review than usual.
7. After approval:
   - push `main` and the tag: `git push origin main v3.0.0`;
   - post the "What's new" text.
