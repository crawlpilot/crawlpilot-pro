# Fonts

From Fontsource (`@fontsource-variable/*` 5.3.0), kept in the repo instead of as npm dependencies:
- Bricolage Grotesque (optical size axis);
- Geist;
- Geist Mono.

All three are under the SIL Open Font License 1.1. Their license texts ship with the extension in `public/licenses/` (`*-OFL.txt`), as the license requires. To update a font, copy its CSS and the `.woff2` files that the CSS references from the new Fontsource release, along with its `LICENSE`.
